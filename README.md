# KOSPI 종가 예측 : LSTM vs ARIMA

노이즈가 심한 금융 시계열에서 다변량 LSTM이 단변량 ARIMA보다 성능이 떨어지는 이유를 분석하고, 그 대안으로 인과적 모델링의 필요성을 정리한 프로젝트입니다.

## 개요

KOSPI 일별 종가 예측을 과제로 두고, 통계 기법인 ARIMA와 딥러닝 기법인 LSTM을 비교했습니다.

처음에는 환율, S&P500, VIX 같은 다변량 정보를 학습하는 LSTM이 단변량 ARIMA를 이길 거라 예상했습니다. 하지만 결과는 반대였고, 저희는 이걸 실패로 덮는 대신 딥러닝이 금융 시계열에서 왜 약한지 분석하는 쪽으로 방향을 바꿨습니다.

핵심 결과는 다음과 같습니다.

- 단변량 ARIMA가 다변량 LSTM보다 RMSE 기준 약 60% 낮았습니다.
- 변동성이 큰 금융 데이터에서 LSTM이 패턴보다 노이즈에 과적합되는 모습을 확인했습니다.
- 단순 성능 경쟁을 넘어 노이즈에 강건한 인과적 모델링이 필요하다는 결론에 이르렀습니다.

사용 기술: Python, TensorFlow/Keras, Statsmodels, Pandas, NumPy, Scikit-learn, yfinance

## 문제 정의

주가 예측은 시계열 회귀 문제이지만, 금융 데이터에는 딥러닝이 잘 통하지 않는 특성이 있습니다. 일별 수익률의 대부분은 예측하기 어려운 확률적 변동이고, 데이터의 분포도 시간에 따라 계속 바뀝니다.

그래서 저희는 이 질문에 답하려 했습니다. 변수를 더 넣고 모델을 더 깊게 만들면 금융 시계열 예측은 정말 좋아지는가.

---

## 데이터와 전처리

Yahoo Finance에서 2005년부터 2025년까지 약 20년치 일봉 데이터를 받아 썼습니다. 예측 대상은 KOSPI 종가이고, 여기에 시가, 고저가, 거래량과 함께 S&P500, 환율, 미 국채 금리, VIX 같은 매크로 변수를 더했습니다.

전처리는 결측치 처리, 로그 변환, 차분과 정상성 검정, 시차 적용, 데이터 분할, 스케일링 순으로 진행했습니다. 미국 시장 변수는 하루 시차를 줘서 KOSPI에 반영되는 시점을 맞췄습니다.

한 가지 신경 쓴 부분은 데이터 누수 방지입니다. 스케일링 전에 데이터를 먼저 나누고, scaler는 Train set에만 학습시켰습니다. 전체 데이터로 스케일링하면 미래 정보가 학습에 새어 들어가 성능이 부풀려지기 때문입니다.

---

## 모델

베이스라인은 단변량 선형 모델인 ARIMA입니다. 로그 변환과 차분으로 정상성을 확보한 뒤 Rolling Forecast 방식으로 예측했습니다.

메인 모델은 LSTM이고, 단변량과 다변량 두 버전을 만들었습니다. 과거 5일로 다음 날을 예측하는 구조이며, Dropout과 EarlyStopping으로 과적합을 관리했습니다.

성능 저하의 원인이 모델 구조 때문인지 입력 변수 때문인지 나누려고 실험군을 세 개로 구성했습니다.

| | 모델 | Feature |
|:---:|:---|:---|
| 1 | ARIMA | 단변량 |
| 2 | LSTM | 단변량 |
| 3 | LSTM | 다변량 |

---

## 결과

| 모델 | Feature | Test RMSE |
|:---|:---|---:|
| ARIMA | 단변량 | 29.79 |
| LSTM | 단변량 | 30.60 |
| LSTM | 다변량 | 74.53 |

1번과 2번의 차이가 거의 없다는 건 LSTM의 비선형 표현력이 이 문제에서 큰 이득을 주지 못했다는 뜻입니다. 2번과 3번의 격차는 변수를 늘린 게 오히려 성능을 악화시켰음을 보여줍니다. 문제는 모델 깊이가 아니라 변수와 타겟 사이에 인과가 아닌 허위 상관이 학습됐다는 데 있습니다.

Train Loss와 Val Loss는 모두 낮게 수렴했는데도 Test 성능이 무너졌습니다. 학습 구간과 테스트 구간의 분포가 달라진 탓으로 보입니다.

---

## 실패 원인

- 노이즈에서 생긴 허위 상관을 학습해, Train에서 성립하던 관계가 Test에서 무너졌습니다.
- 외부 충격으로 분포가 이동할 때 모델이 강건성을 확보하지 못했습니다.
- 예측이 직전일 가격을 거의 따라가는 경향이 있어, 실질 예측력이라기보다 단순 반복에 가까웠습니다.
- 변수 관계가 블랙박스로 처리돼, 어떤 변수가 어떻게 작용했는지 설명하기 어려웠습니다.
